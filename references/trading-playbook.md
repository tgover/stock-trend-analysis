本文件用于把课程战法转为“前提—触发—确认—失效—退出”的可执行条件。任何形态都不能脱离市场、板块和标的角色单独使用。

## 1. 通用前置过滤

应用任何战法前回答：

1. 市场是趋势、情绪、轮动还是退潮环境？
2. 板块是启动、强更强、分化、修复还是退潮？
3. 标的是核心、前排、后排、套利品还是角色不清？
4. 日线结构是否仍有更高高点/更高低点或有效平台？
5. 触发位、失效位和潜在上行空间能否形成合理风险收益？
6. 是否临近财报、解禁、监管、宏观数据或重大事件？
7. 当前风格是否属于自己能够稳定执行的策略范围？
8. 计划周期是否在入场前定义，还是被套后才从短线改口为长期？

任一核心问题无法回答时，优先观察而不是强行生成买点。

### 先写预期账本再开盘

任何盘前计划先写：

1. 原状态和无新变量时的基准路径；
2. 足以升级的正向变量；
3. 足以降级的负向变量；
4. 每个变量对应的动作上限。

开盘后只做三件事：验证变量是否出现、检查是否持续、按事先动作映射执行。单只股票翻红、瞬时爆量或消息刺激不单独改写剧本。若证据不足，维持原预期并等待下一检查点。

### 盘前选择执行模式

- **核心持有型**：适合希望减少切换的人。只持有已经通过环境、板块和角色验证的核心；普通分歧不临时做高频差价，核心失去带动或环境失效时才减风险。
- **节奏交易型**：只在环境安全、分歧—回流边界清楚且能够持续盯盘时使用。分歧时等待核心承接，回流/一致时保护利润；每次仍需独立触发和失效。
- **仅观察**：若执行类型不清、市场风格不匹配或盘中无法验证变量，主动选择不参与。

盘前把模式、允许动作和禁止动作写入计划。盘中不能因为上涨怕踏空而从持有型切成追涨，也不能因为一根阴线从持有型切成高频止损。

### 左侧与右侧的成本—确定性交换

- **左侧候选**：下探时价格不再加速创新低，成交显示卖压衰减，跌停/深跌不扩张、核心有承接且硬失效可定义。缩量只是其中一项线索，不能单独证明安全。优势是成本可能更低，代价是仍可能继续下跌，只允许小风险试错。
- **右侧候选**：价格转强、量能持续、回踩承接和板块共振形成证据链。成本可能更高，但确定性更强。
- **禁止事项**：不把“下跌就是机会”解释为无条件补仓；放量破位、核心松动或退潮时终止左侧假设。

### 环境—形态闸门

- 先填指数轴与情绪轴，再解释K线。指数弱、情绪稳定只说明可能处于结构分化或震荡，不等于自动出现低吸点；指数强、情绪弱时不因大阳线追指数。
- 同一种缩量回踩、长下影、大阳或弱转强，在上升延续、震荡消化和退潮环境中的含义不同。环境、板块与角色任一失效，形态信号降级。
- 课程中的“下探可以出手”必须翻译为条件句：只有卖压衰减、负反馈不扩张、核心承接、近端硬失效与风险收益同时成立时，才进入左侧小风险候选；否则继续观察。

### 密集套牢供给闸门

- 快速下跌或多次失败启动形成的密集套牢区，不能靠一根大阳或盘中触及直接认定突破。
- **资金换空间**要求持续有效增量同时支持价格、宽度、容量核心和板块扩散；只有权重放量或单线脉冲不通过。
- **时间换空间**要求震荡换手后供给逐步下降，并由缩量回踩不破、核心承接和首次回踩验证；“磨了若干天”不是证据。
- 接近供给区且两类消化证据都不足时，动作上限为等待确认；强拉后无承接优先防冲高兑现。

### 极端退潮覆盖规则

当市场出现宽度断层、跌停快速扩张、容量核心集体破位或指数争夺关键位时，先暂停普通个股战法：

1. **止跌检查**：低开或盘中下探本身不是否决项，但卖出量应收缩、跌停不再扩张、关键指数不再连续创新低。
2. **修复检查**：若价格向上修复，需成交逐步放大、上涨宽度改善、容量核心参与，而不是只有小票脉冲或无量高开。
3. **路径检查**：前一普涨日后紧接极端普跌，会留下大量套牢供给；首个反包日默认只是反弹候选。
4. **升级条件**：后续1—2日成交结构改善（可温和放量，但不要求爆量）、宽度不显著回落、负反馈尾部收敛、核心完成分歧承接并带动板块，才从止跌升级为反转/主升候选。
5. **动作约束**：混沌或状态切换异常期以观察和小风险试错为上限；不能因为消息强、图形漂亮或主观长期看好放大风险。

### 修复信号四级门

1. **左侧止跌信号**：不再加速创新低、恐慌卖压衰减或出现普反；动作仍是观察。
2. **次日结构确认**：关键位不再破坏，价格路径和成交结构未再次失控。
3. **负反馈尾部收敛**：跌停、深跌、炸板、容量核心破位和后排大面至少不再扩张；否则即使指数或K线好看也不得升级。
4. **新周期/主线扩散**：新方向出现赚钱效应、核心带动和首次分歧承接后，才允许从观察升级为小风险试错。

关键位上的成交量必须结合前一日驱动结构判断。权重推动的急修复后再次爆量猛冲，可能触发兑现；放量下破关键位则可能直接失效。小阴小阳、波动收敛和温和换手常是供给密集区的理想路径，但不是机械买点。

### 周期切换三类观察池

- **超跌修复**：默认按反抽；持仓者优先把反弹当减风险窗口，新开仓仍需右侧触发。
- **穿越候选**：先看极端弱市的抗跌/率先止跌，再看修复日能否主动领涨、带动扩散；只有前者时仍是防御性幸存者。
- **新题材候选**：火苗只观察；扩散到同逻辑标的、获得有效成交并完成首次分歧承接后再升级。

同一市场边界上的多次启动失败会累积套牢供给。失败启动中的题材或个股先降级，不能因再次反弹恢复原预期；需等待市场状态重置和独立新证据。

### 急跌反弹的分类窗口与不追规则

急跌后的大阳、V形拉回或单日普涨，默认只提供“反弹候选”而不是追高许可。首日及随后1至3个交易日按以下条件分类：

- **物理性反弹/修复初期**：主跌方向只是反抽，负反馈尾部未沿路径收敛，或旧主线出现高成交全链条破坏；动作是观察、已有仓位借反弹评估减风险，不追急拉。
- **修复扩散**：多个独立超跌方向分批改善，旧主线仅温和分化，深跌/跌停/炸板与容量破位不再扩张；动作仍以等待核心的回踩承接或首次分歧修复为主。
- **新阶段待确认**：在修复扩散基础上，容量核心持续带动、有效增量支持广度，候选方向完成首次分歧承接；才允许小风险试错，仍不把它写成主升已确认。

V形反转若未参与，不得用盘后走势证明应当追涨。将其标为“错过的脉冲”，转而等待：回踩不破关键结构后的转强、首次分歧承接，或市场/板块/核心重新共振的右侧信号。若没有近失效位和至少约1.5—2R空间，继续不参与。

记录负反馈时必须看路径：开盘、午间、收盘和随后交易日的跌停、深跌、炸板、后排大面与容量核心破位。只看收盘时一项尾部数据，不能判定全面修复。

## 2. 涨三天不追与回调转强

### 适用对象

- 机构主导或容量型趋势股；
- 已形成上升结构，板块与市场未进入退潮；
- 连续三日上涨，或三日内出现明显冲量加速。

### 规则拆解

#### 第3个上涨日：不追

- 标记三日高点、低点、收盘、成交量和关键均线；
- 检查是否出现加速缺口、巨量、长上影、尾盘回落或板块高潮；
- 即使第4/5日可能继续涨，也不因害怕踏空而在第3日情绪化追高。

例外不是“可以买”，而是需要独立形态：高质量平台突破后的回踩确认、市场/板块共振且止损很近等。

#### 调整第1天：观察

- 观察缩量还是放量下跌；
- 标记调整低点、5/10日线、前平台和三日启动位；
- 检查板块核心是否同步转弱；
- 默认不把第一根阴线直接当低吸点。

#### 调整第2/3天：等待转强

合格触发可包括：

- 收复前一日高点、开盘价、VWAP、5/10日线或平台边缘；
- 盘中停止创新低并形成更高低点；
- 放量上涨但不是失控式脉冲，或缩量回踩后温和放量；
- 板块核心/指数同步改善。

失效信号：

- 跌破调整低点或关键平台并放量；
- 所谓转强始终受压于关键阻力，尾盘再次转弱；
- 板块进入退潮或核心失去带动性；
- 预期上行空间小于合理止损距离的约1.5—2倍（按策略自行设阈值）。

### 形态标签

- 第1天回调观察；
- 第2天转强候选；
- 第3天转强候选；
- 弱开后企稳，待尾盘确认；
- 加速未参与；
- 结构失效。

输出时必须明确当前属于哪个标签。

## 3. 弱转强识别

“弱转强”是相对前一日预期的变化，不等于“今天上涨”。先定义前一日为何弱，再定义今天用什么证据推翻弱预期。

### 前一日的弱

- 跌破/失守10日线、平台或分时均线；
- 冲高回落、收盘弱、板块分化；
- 放量下跌或预期次日继续承压。

### 集合竞价弱转强（A股）

候选条件：

- 前一日确实弱，次日竞价却明显高于弱势预期；
- 红开或高开有合理成交支持，不是极小量虚价；
- 板块和市场没有同步显著恶化；
- 开盘后能守住竞价/开盘关键位。

仅“红开”不够。若高开低走、快速跌破开盘低点或板块核心转弱，信号失效。

### 盘中弱转强

候选条件：

- 低开后不再创新低，形成更高低点；
- 放量翻红并突破日内前高或关键参考位；
- 回踩不破突破位/VWAP，或快速收回；
- 同板块核心与指数至少不构成明显拖累。

### 真假辨别

| 真转强证据 | 假转强风险 |
|---|---|
| 突破后保持、回踩承接 | 单笔脉冲后回落 |
| 量价配合且板块响应 | 个股独拉、板块继续退潮 |
| 收复关键结构 | 只翻红但仍在压力下 |
| 尾盘仍能确认 | 早盘强、午后量能和价格衰减 |

## 4. 退三返一

### 课程定义

标的跌破10日线后向后观察3个交易日；若收盘不再创新低、未有效破位，第3日出现弱转强，视为回归趋势的博弈候选。

### 完整条件

1. **前提**：跌破前是可识别的上升趋势或核心标的，不是长期下降趋势中的随机反弹。
2. **退三**：三个交易日内卖压衰减，低点不持续下移，最好伴随缩量或承接改善。
3. **返一**：第3日或之后收复至少一个关键参考位（前日高、10日线、平台、VWAP等）。
4. **环境**：板块没有退潮，核心逻辑未被证伪。
5. **失效**：新低、放量破位、反弹无量且受压、重大基本面利空。

不要因为“已经第3天”自动进场；日期只是观察窗口，转强才是触发。

若此前已按计划止损，新的合格形态可重新评估；不要因沉没成本拒绝，也不要为“买回来证明自己”而交易。

## 5. 板块分化与核心管理

### 分化期

- 后排和纯跟风标的优先降低风险；
- 不因位置低就买入“看高做低”标的；
- 核心可继续观察，但需检查其是否仍有带动性；
- 比较轮动方向时，用同期相对强度和成交结构，不凭主观喜好。

### 观察池压力测试

- 连续两根或多根弱K线只触发降级检查，不自动卖出；结合板块、量能和关键结构判断。
- 板块修复时仍落后、反弹无量或无法收回关键位者，利用反弹重新评估/淘汰。
- 分化中抗住只获得观察资格；修复日主动领涨、带动扩散并具备挑战新高能力者才升级为重点。

### 四层角色反馈与分化动作

把观察池固定分为容量核心、高度核心、前排、中位/后排：

- 容量与高度核心稳定、前排有承接、中位/后排掉队：按强转分化处理，减少中后排，不因尾部噪声否定全部核心；
- 高度核心转弱、容量核心稳定：情绪降温，停止新增中位接力，观察是否向趋势轴外溢；
- 容量核心转弱、高度核心稳定：可能是风格分裂，趋势玩法降级，不能用小票高度掩盖机构轴风险；
- 两条核心轴补跌、前排失去带动、中后排和跌停扩张：退潮/风险确认，暂停普通低吸与弱转强战法。

中位股只有出现独立带动、健康换手和分歧修复，才可升级角色；“位置较高”本身不是核心证据。

### 外围预警与低位补涨

- 套利品、后排和中位先转弱，说明利润空间收缩或核心开始孤立；先提高警觉、停止新增外围风险，不据此直接猜顶。
- 若负反馈继续传到前排，再传到情绪高度/机构容量核心，并伴随跌停尾部扩张，才逐级提高减风险优先级。
- 低位补涨活跃说明资金尚未完全离场，但也可能说明旧核心顶不上去；只参与已形成独立带动和清晰失效的新承载候选，不把“位置低”当安全。

### 分歧与一致的条件化使用

- 方向未失效、不同风险链路核心仍稳、尾部不扩张且首次回踩有承接时，分歧才可形成观察或小风险试错窗口。
- 多核心共振转弱、放量破位或跌停扩张时，分歧属于风险释放，不是低吸信号。
- 一致伴随加速、成交失控和板块扩散收缩时提高兑现警报；一致若由全市场有效增量和健康扩散支持，不机械卖出。

### 强更强

- 持仓核心可顺势管理，但新开仓要评估加速、拥挤和次日兑现风险；
- 板块广度、核心强度与市场热度必须相互印证；
- “强更强”不是加仓指令，必须仍有合格风险收益。

### 退潮

- 核心与跟随集体转弱、负反馈扩散时，优先控制风险；
- 不用历史涨幅或“龙头信仰”替代失效规则；
- 等待亏钱效应收敛、核心止跌和新周期证据。

## 6. 龙头、跟风与套利品

### 龙头仍在创造板块效应

- 龙头走强时，板块上涨家数/涨停/成交同步扩散；
- 分歧时有跟随股承接，次日能修复；
- 龙头可交易后，板块仍有新增资金而非只在核心内部拥挤。

### 龙头开始高位吸血

警报组合：

- 龙头维持高位，后排却持续冲高回落或大跌；
- 板块扩散、成交和涨停梯队连续收缩；
- 龙头开板后套利品立即失去承接；
- 龙头自身的上涨不再改善板块赚钱效应。

出现一次不直接判顶；连续两次或与放量分歧、板块退潮共振时，提高退出优先级。

### 套利品规则

买入逻辑候选：核心因一字板等原因不可交易，强度已确认，套利品流动性良好且可低风险参与。

退出条件：

- 核心开板并恢复可交易，资金回流核心；
- 板块从强转分化或进入退潮；
- 套利品冲高回落、跌破分时/VWAP且无法收回；
- 套利品相对强度明显落后。

若套利品出现独立订单、业绩或事件催化，应重新评估其角色，而不是机械按依赖品处理。

## 7. 日内检查点

仅适用于交易时段和对应市场制度。

### A股常用时点

- 集合竞价（9:25）：检查预期差、竞价成交真实性和推算全日成交额；只记资金意图，不直接升级动作；
- 9:35—10:00：将推算成交额与前一日/5日均值比较，确认量能是否持续，并同步检查宽度、容量核心和跌停尾部；
- 开盘后30分钟：确认弱转强、板块扩散和主线带动是否能保持；
- 10:00/10:30：检查第一次回踩和板块响应；
- 14:00：检查午后是否有增量资金；
- 14:30：对无法持续盯盘或弱开候选做尾盘确认。

### 集合竞价三阶段验证

1. **9:15—9:20可撤单阶段**：只记录极端挂单和资金试探，不把大封单或跌停单直接当真实供需；
2. **9:20—9:25不可撤单阶段**：检查前一日受伤的容量核心、高度核心和中位负反馈是否被保留、修复或继续扩大，并核对真实竞价成交；
3. **9:30后首次下探**：检查下探是否放量、核心能否收回、板块是否响应；最终高开但开盘即失守时，按假强降级。

若数据源只能返回9:25最终价、不能返回挂单/撤单路径，明确写“竞价过程不可验证”，不使用“抢筹”“核按钮被承接”等过程性结论。

### 14:30低吸候选条件

- 调整第2/3天，而非第1天盲接；
- 全天不再创新低，关键支撑未破；
- 尾盘价格稳定在VWAP/关键位附近或重新收复；
- 市场和板块风险可控；
- 次日跳空风险与止损可接受。

14:30只是检查点，不是自动买点。港股、美股不能照搬A股收盘结构和T+1约束。

### 开盘四种映射

| 开盘结构 | 定性 | 动作上限 |
|---|---|---|
| 量能持续增加、上涨宽度改善、容量核心与板块同步 | 有效增量/右侧确认候选 | 等首次回踩承接后，小风险试错 |
| 指数上涨但宽度弱、成交集中少数权重 | 权重假强 | 不追指数，不把权重成交当全市场增量 |
| 缩量下探、尾部不扩张、核心有承接 | 卖压衰减/轮动修复候选 | 观察；仅有清晰失效时左侧小试错 |
| 高成交下杀、跌停/深跌扩张、核心破位 | 风险确认 | 减风险或不参与 |

## 8. 低风险训练与执行成熟度

市场存在机会，不代表交易者已经具备稳定执行能力。只有满足以下条件，才进入“低风险训练模式”：

- 只练一种明确模式，市场、板块、角色前提清楚；
- 触发、硬失效、软失效和时间失效可在出手前写出；
- 即使判断错误，风险也不会破坏下一次正常执行或诱发报复性交易；
- 过程可记录、可复盘、可重复，不依赖临场灵感；
- 当前风格属于自己能理解的范围，不因市场只剩连板或高波动机会放宽标准。

执行尚不稳定时：降低同时观察的方向和标的数量，降低频率和风险预算，优先等待右侧确认；不能用提高仓位来“逼自己认真”。

将“靠意志执行”改成环境设计：盘前只保留与当日模式相关的核心温度计，预设检查点和动作上限，隐藏不属于模式的临时机会；训练从错误也不会破坏下一次执行的场景开始，再逐步增加变量。环境设计不能替代止损和风险预算。

每次训练固定记录：

1. 原预期与基准路径；
2. 第一个跨过闸门的有效变量；
3. 实际动作是否符合预案；
4. 偏差来自信息缺失、判断错误还是执行失控；
5. 下一次只改一条可执行规则。

盈亏只是结果字段，不能替代过程复盘。连续盈利也要检查是否因证明欲、题材身份或风险预算膨胀而放宽标准。

## 9. 失效与退出

### 价格结构失效

- 跌破调整低点、平台或定义形态的关键位；
- 放量破位后无法快速收回；
- 弱转强突破失败并重新跌回原区间。

### 板块/角色失效

- 板块退潮、核心失去带动性；
- 标的从核心降级为后排，或套利依赖消失；
- 原题材催化被证伪或时间表大幅推迟。

### 时间失效

- 预期应快速转强但连续数日无动作；
- 资金占用导致机会成本上升；
- 事件窗口已过但市场没有验证逻辑。
- 短线触发失败后才把计划改成长期持有，属于周期漂移而不是新证据。

### 下跌趋势反抽的减风险规则

- 卖压衰减、连续急跌后的技术反抽，不等于外部增量进场。
- 未完成结构确认和负反馈尾部收敛前，持仓反抽优先用于减风险，不预设反弹高度。
- 不因“跌得多、性价比高”自动生成新开仓；若仍要观察，必须给出右侧触发和反抽低点失效。
- 反抽后再次转弱或无法改善板块反馈，维持下跌趋势定性。

### 退出表达

不要只写“止损价”。同时写：

- 硬失效：触及即认错的结构条件；
- 软失效：需要减仓/观察的板块或时间条件；
- 保护利润：加速、放量滞涨、核心吸血时的减风险条件；
- 重新评估：何种信号出现后可以重新纳入观察，而非摊低成本。
