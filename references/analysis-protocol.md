本文件用于保证分析可复核、可执行且不过度确定。先验证数据，再给结论；评分用于组织证据，不用于制造精确幻觉。

## 1. 最小数据集

### 个股短线/波段

- 市场、代码、名称、分析日期与时区；
- 至少60个交易日OHLCV，最好含复权说明；
- 5/10/20/60日均线或足够数据自行计算；
- 对应指数与板块同期行情；
- 当日分时/VWAP（若分析日内触发）；
- 最新公告、财报、重大事件与停复牌/监管风险；
- A股需注意涨跌停、T+1、ST/北交所/科创创业板制度差异。

### 市场/板块复盘

- 主要指数涨跌、成交额及5/20日对比；
- 指数轴与情绪轴分别记录：指数贡献/关键位；上涨下跌宽度、尾部、容量/高度核心与各角色反馈；再标记同步向上、同步向下或错位。
- 上涨/下跌、涨停/跌停、连板高度、炸板率；
- 板块涨跌、成交额、成交占比和核心股表现；
- 风格指数或代表性ETF的相对强弱；
- 当日重大宏观、政策、产业与公司事件。
- 最近至少5日同源同口径的宽度、涨跌停、连板与成交路径；若口径变化，记录差异而不强行续接。
- 极端波动后的盘中卖出量、跌停扩张时点、容量核心响应和次日供给消化情况。
- 将首日风险记为负反馈种子，记录开盘—午间—收盘—次日及后续是扩大、维持还是收敛，并区分情绪受压与全面退潮候选。
- 正向宽度与负反馈尾部并列：上涨家数、涨停/晋级之外，同时记录跌停、深跌、炸板、后排大面和容量核心破位。
- 总成交容量与核心类型的适配：高度轴、成交额轴、机构容量参与度及其变化。
- 急跌反弹时记录同口径的开盘、午间、收盘及随后1至3日路径：旧主线是温和分化还是高成交破坏，独立修复方向的数量，和负反馈尾部是否持续收敛。
- 接近密集套牢供给区时，记录供给来源、有效增量承接证据、时间/换手证据及首次回踩结果；不得只记录一根突破K线。
- 盘前/开盘计划另记录前一日与5日平均成交额、宽度、涨跌停、容量轴和高度轴；9:25竞价推算量与9:35—10:00持续量必须分开。
- 盘前/盘中增加预期账本：原状态、无新变量时的基准预期、正向变量、负向变量及各自动作上限。
- 将负反馈按容量核心、高度核心、前排、中位/后排四层记录，避免把中位补跌直接等同于核心退潮。
- 若要评价集合竞价过程，执行竞价三阶段验证：记录9:15—9:20、9:20—9:25与开盘首次下探；数据源缺少挂单/撤单路径时，只能评价最终竞价结果。
- 市场健康度另记录领涨板块成交占比、剔除领涨板块后的宽度、非领涨容量核心和尾部路径，用于区分共生上涨与单线吸血；数据不支持剔除计算时明确缺失。
- 每个核心温度计记录风险链路归属（情绪高度、机构容量、指数贡献或具体主线）及负反馈传导层级；不使用无归属的“核心都很好/都很差”。
- 基本面高增长场景记录报告期与同比/环比口径、一致预期、股价先行幅度、可比同业与增长质量。

数据缺失时不要伪造。说明哪些结论只能定性、哪些无法确认。

## 2. 证据层级

按可靠性优先：

1. 交易所/公司公告、正式财报、监管披露；
2. 可复核行情数据与指数/板块统计；
3. 公司官方交流、权威产业数据；
4. 主流媒体与卖方观点；
5. 资金身份、市场情绪和题材叙事推断；
6. 课程口号、社交媒体传闻和主观印象。

对第5—6层使用“可能、偏向、待验证”，不得写成事实。

将量化交易、杠杆平仓、ETF申赎、国家队或外盘联动等原因归入第5层；除非有对应的成交结构、两融、基金份额或明确事件时点证据，不得把同步波动直接等同于单一原因。

## 3. 六层分析表

每层给出“支持、反证、结论”，必要时用0—2分组织证据：0弱/不利，1混合，2强/有利。总分不能替代失效规则。

### A. 市场环境

- 指数趋势与关键位置；
- 指数轴与情绪轴各自的方向、证据和同步/错位状态；指数红绿不得替代赚钱效应。
- 总成交额与宽度；
- 风格主导权；
- 系统性事件风险。
- 当前位于左侧止跌、结构确认、尾部收敛还是新周期扩散；是否存在价格修复而负反馈扩张的K型修复。
- 反弹性质是物理性/超跌反弹、修复扩散还是新阶段待确认；旧拥挤主线的让位是否有序。旧线高成交全面破坏时，不得把其他方向上涨解释为健康切换。
- 趋势方向、突破时点和当前可交易性分别判断；接近历史供给密集区时，检查有效增量和时间/换手是否足以消化供给。
- 写出基准预期及正负变量；若没有变量跨过闸门，维持原状态，不因盘中噪声改口。
- 明确阶段标签及证据：反弹、反转候选/确认、二波候选/确认或不清楚。低位补涨和单日普涨不能单独完成升级。
- 报告市场健康度：共生、单线吸血、混合或不清楚；领涨强度与全市场健康度分开评分。
- 标记负反馈种子是扩大、维持还是收敛；只有跨角色、跨链路且与尾部、宽度共振恶化，才从“情绪受压”升级为全面退潮候选。

### B. 板块质量

- 相对强度与持续天数；
- 成交额/份额是否提升；
- 广度、梯队与核心带动；
- 第一次分歧后的修复。
- 方向来源是超跌修复、穿越候选还是新题材；是否继承了此前失败启动的套牢供给。
- 低位补涨是在旧核心盘整期轮动，还是在旧线释放空间后形成了新的容量、扩散和首次分歧承接。

### C. 标的角色

- 成交额/高度排名；
- 带动性和独立性；
- 流动性与交易可达性；
- 机构核心、情绪龙头、前排、后排或套利品。
- 弱市抗跌与修复日领导力分别评分；最高板和成交额最大分别作为高度轴、容量轴。
- 单列前排与中位/后排：中位的位置和高度来自核心打开空间时，不等同于独立领导力；检查其换手、带动与分歧修复后再升级。
- 给核心注明风险链路；按套利/后排预警—中位/前排传导—核心确认—指数/量能/尾部共振记录风险到达的位置。

### D. 价格与量能结构

- 高低点结构、平台和均线；
- 放量突破、缩量回调或放量破位；
- 当前处于启动、延续、加速、回调、修复还是破位。
- 先说明环境与角色，再解释形态；同一K线不得脱离双轴状态和负反馈路径定性。
- 将量能按恐慌卖出、卖压衰竭反弹、有效增量买入、兑现/派发归类；缩量同时检查卖压收敛和主动买盘不足两种解释。
- 供给密集区说明依靠有效增量还是时间/换手消化，以及持续量、维持/收盘和首次回踩是否通过。

### E. 催化与基本面

- 催化是否已发生、可持续、可量化；
- 业绩、产能、订单、渗透率与估值；
- 预期差、时间表和可能证伪点。
- 高增长或低估值必须增加“报告口径—一致预期—价格已交易程度—同业质量”核验；基本面评分与当前可交易性分开。

### F. 交易可执行性

- 清晰触发与失效位；
- 上行空间、止损距离和流动性；
- 隔夜/财报/政策风险；
- 是否符合用户所问周期。
- 当前风格是否在用户可稳定执行的策略范围；是否存在短线失效后改口长期的周期漂移。
- 执行成熟度是否允许真实风险：触发/失效能否事前写清、错误是否会影响下一次执行、模式能否低风险重复练习；不满足时降低复杂度、频率和风险预算。
- 盘前执行模式是核心持有型、节奏交易型还是仅观察；盘中动作是否发生了未经预案允许的模式漂移。

### 一票否决

即使综合证据较好，以下情况也优先“不参与/等待”：

- 无法定义失效点；
- 已明显退潮或放量破位；
- 流动性不足、连续一字不可成交或滑点不可控；
- 重大事件前风险无法承受；
- 数据互相矛盾且无法核验；
- 潜在收益不足以覆盖止损和交易成本。
- 指数/K线改善但跌停、深跌、炸板或容量核心破位继续扩张，修复质量未通过。

## 4. 情景推演

用条件句代替单点预测。

### 基准情景

列出当前证据最支持的路径及触发条件，例如：“若板块维持成交占比、个股守住10日线并收复前高，偏向回调后延续。”

### 乐观情景

说明需要哪些额外证据，例如市场放量、核心新高、板块扩散和个股突破。

### 风险情景

说明什么会推翻逻辑，例如跌破调整低点、板块核心转弱、催化证伪。

不要给未经数据支持的概率。若必须排序，可用“最符合/次符合/低概率但高影响”。

### 变量闸门与不变规则

- 基准情景描述“没有新变量时”原状态如何延续；
- 乐观情景必须列出足以升级的正向变量，不用单一红K线或消息替代；
- 风险情景必须列出足以降级的负向变量，并说明先影响哪个角色层级；
- 若正负变量都未形成完整证据链，保持原定性并等待下一检查点；
- 正负变量同时出现时标记混合状态，优先降低动作上限，不强行选边。
- 指数与情绪不同步只改变基准路径，不自动产生交易动作；若双轴重新同步且有成交、尾部和核心证据，再升级或降级。
- 首日风险种子没有跨日扩散时，不直接判全面退潮；但“情绪未崩”也不能替代触发、失效和风险收益。

### 次日盘面推演规则

日度市场复盘不以“预测一根K线”为目标，而以次日出现不同盘面时能够切换行动为目标：

- 先定性为下跌中继、止跌/反弹候选、反弹途中、反转确认或不清楚；
- 将量能拆为恐慌卖出量、少数权重指数贡献量、全市场有效增量；
- 至少给出最理想/基准、可接受的确认、风险/失效三条路径；
- 每条路径都绑定宽度、涨跌停、核心与后排、板块扩散、成交结构等可观察条件；
- 依次检查集合竞价、开盘后30分钟、10:30首次回踩和14:00—14:30午后确认；
- 先用“从哪里来—为什么在这里—接下来去哪里”写三问定位；9:25只记录量能意图，9:35—10:00验证持续量、宽度、容量核心和负反馈尾部，10:30验证首次回踩承接；
- 每条路径明确“可以做、不要做、何时才能提高风险”，避免把方向判断直接写成无条件买入建议。
- 明确当前修复等级：左侧止跌信号、次日结构确认、负反馈尾部收敛或新周期/主线扩散；不得跳级。
- 对急跌后的强反弹另给分类结论：默认使用首日及随后1至3日作为观察窗口；写清旧主线状态、至少两个独立修复方向是否形成接力、尾部路径和有效增量是否通过。该窗口用于验证，不是固定天数的自动升级规则。
- 将候选按超跌修复、穿越候选、新题材候选分类，并说明升级到可执行计划还缺什么。

## 5. 风险收益与仓位

### R倍数

设计划入场价为 `E`，失效/止损价为 `S`，目标或合理压力位为 `T`：

- 多头每股风险：`R = E - S`；
- 潜在收益：`T - E`；
- 风险收益比：`(T - E) / (E - S)`。

若 `S >= E`、目标不清或价格数据不足，则写“无法计算”，不要编造。

### 风险预算仓位

- 账户允许损失额 = 账户权益 × 单笔风险比例；
- 理论数量 = 允许损失额 ÷（入场价 − 止损价）；
- 再受最大仓位、最小交易单位、流动性、跳空风险和交易费用约束。

课程中的20%—30%试仓只是案例，不作为默认比例。没有用户账户规模与风险偏好时，只讲公式和相对大小，不给个人化仓位指令。

市场阶段先限制可使用的风险预算：退潮/状态切换异常趋近于零，混沌只用可重复试错的小部分预算，右侧确认后再随证据增强。调整的是风险敞口，不是用固定仓位比例替代个股止损和总风险上限。

风险预算还受策略能力约束：市场切换到不熟悉的情绪、连板或高波动风格时，不因“当前只有这种机会”而放宽标准。周期必须在入场前定义；短线失效后不得通过改名长期持有绕过止损和时间失效。

低风险训练不以固定小仓位定义，而以“错误不会破坏下一次执行、触发与失效清楚、可以重复复盘”定义。若连续出现计划外追涨、止损后报复性出手或短线改长期，停止提高风险，先降低模式复杂度和频率。

### 跳空与事件风险

止损不能保证成交在止损价。财报、监管、宏观事件和连续跌停会使实际亏损大于计划值；因此需降低风险预算或回避事件窗口。

## 6. 置信度

- **高**：价格、量能、板块、角色与催化大体一致，数据新鲜且无重大反证。
- **中**：核心逻辑成立但有一至两个关键变量待确认。
- **低**：数据缺失、证据冲突、角色不清或依赖主观资金推断。

置信度不是胜率。即使高置信度也必须有失效点。

```markdown
市场状态：...
主导风格：...
指数—情绪双轴：指数轴...；情绪轴...；同步/错位...
预期账本：原状态 / 基准预期 / 正向变量 / 负向变量
强更强：...
强转分化：...
退潮/负反馈：...
负反馈扩散：首日种子；扩大 / 维持 / 收敛；风险传导到...
角色反馈矩阵：容量核心 / 高度核心 / 前排 / 中位与后排
供给消化：有效增量 / 时间换手 / 尚未消化；首次回踩证据...

次日盘面推演
- 三问定位：从...来；当前因...位于...；次日关注...三条路径
- 开盘基线：前一日/5日平均成交额、宽度、涨跌停、容量轴、高度轴
- 开盘验证：9:25意图 / 9:35—10:00持续量与宽度 / 10:30首次回踩
- 当前定性/主要矛盾：...
- 预期与变量：无变量时的基准路径 / 正向升级变量 / 负向降级变量
- 量能结构：恐慌卖出量 / 权重指数量 / 全市场有效增量
- 最理想/基准路径：若...则...；可以...；不要...
- 可接受的确认路径：若...则...；风险升级条件...
- 风险/失效路径：若...则...；减风险/不参与条件...
- 检查点：集合竞价 / 10:00 / 10:30 / 14:00—14:30
- 方向角色：修复方向 / 穿越候选 / 新题材候选（全部待当日数据验证）
```

### 反事实复盘

每次明显判断偏差至少记录：原主要矛盾、当时可见证据、实际只符合了原预期的哪一部分、最早失效信号、是否执行、事后才知道的信息、仍未证实的归因，以及下一次可直接复用的一条规则。连续判断正确也要检查是否出现证明欲、题材身份或风险预算膨胀。只总结结果会产生事后聪明；复盘目标是找到当时可以执行的改进。

低风险训练另记录：原预期、第一个有效变量、计划动作、实际动作、偏差类型和下一次只改的一条规则。不要把盈亏当作唯一评分。

## 8. 质量检查

输出前逐项检查：

- 是否标注了准确时点并区分盘中/收盘？
- 是否完成三问定位，并把9:25瞬时量与9:35—10:00持续量分开？
- 是否写出预期账本，并说明什么变量足以改变剧本；没有变量时是否保持原判断？
- 是否分别填写指数轴与情绪轴，再判断同步/错位，而非用指数红绿替代赚钱效应？
- 若评价竞价过程，是否区分可撤单、不可撤单与开盘首次下探；缺过程数据时是否明确降级？
- 宽度、涨跌停和成交额是否来自同源同口径，主要矛盾是否明确？
- 是否识别了相邻交易日的状态切换异常和套牢供给，而非只看当天截面？
- 是否标注止跌/修复四级门，并同时报告正向宽度与负反馈尾部？
- 是否记录负反馈种子跨检查点与跨日的扩大/维持/收敛，并区分情绪受压与全面退潮？
- 是否把抗跌误写成领导力，或把失败启动中的候选直接恢复为主线？
- 是否检查总成交容量与高度核心/容量核心的适配？
- 是否分别报告容量核心、高度核心、前排、中位/后排，并避免把中位补跌写成核心退潮？
- 是否把趋势未破、供给消化、突破时点和当前可交易性混成同一结论？
- 接近密集套牢供给区时，是否验证有效增量或时间/换手及首次回踩，而非用一根大阳线确认突破？
- 是否对缩量同时检查卖压衰减与买盘不足两种解释？
- 是否区分领涨方向强度与全市场健康度，并用板块外宽度判断共生还是吸血？
- 是否为反弹、反转、二波提供了各自证据，而非用固定天数、金额或单日上涨命名？
- 是否给核心温度计标明风险链路，并区分外围预警、结构传导、核心确认和全面共振？
- 是否把低位补涨的场内活跃与旧核心天花板两层含义都写出，并验证新承载方向的出现时点？
- 多主线候选竞争时，是否允许“未决”，并在市场选择节点比较而非普通轮动日强行二选一？
- 是否把历史案例误写成当前主线？
- 是否同时分析市场、板块和个股，而非只看K线？
- 是否把“资金行为”明确标为推断？
- 是否给出至少一条支持证据和一条反证？
- 是否给出明确触发、失效和时间条件？
- 是否检查策略能力匹配和短线改长期的周期漂移？
- 是否在盘前选择执行模式，并检查盘中有没有从持有型、节奏型或观察型临时漂移？
- 高增长/低估值场景是否核验报告口径、一致预期、价格先行和同业质量，并与可交易性分开？
- 是否检查低风险训练条件，避免在执行尚不稳定时提高复杂度、频率或风险？
- 日度盘后复盘是否另列次日盘面推演，并拆分量能性质、三条路径、盘中检查点和行动映射？
- 是否避免“必涨、必跌、稳赚、绝对安全”等词？
- 是否避免机械推荐满仓、杠杆或摊平亏损？
- 是否避免把课程中的绝对成交额、固定板块和固定仓位写成永久规则？
- 是否说明数据缺口与置信度？
- 是否把用户要的结论放在最前面？
